If you want to perform comparison on string then go for test command.
	there is also an alternative syntax to test command. 
	i.e., [ command ].
	
	Here Square bracket is used as an alternative to test command.
	
	test -z "$var"
		returns true if string is null 
		
	test -n "$var"
		returns true if string is NOT null 
	
	test "$varOne" = "$varTwo"
		compares two strings for equality
	
	[ "$varOne" != "$varTwo" ]
		compares two strings for Not-equal
	
	You can use test command to perform operations on files as well.
	
	[ -e filename ]
		returns true if file exists
	
	[ -f filename ]
		returns true if file exists and is a normal/regular file.
	
	[ -d filename ]
		returns true if file exists and is a directory.
	
	Plenty of other options available with test command. You can refer to manual page.	
	
	Test command can also be used to compare numbers 
		-eq --> equal to 
		-ne --> NOT equal to 
		-gt --> greater than
		-ge --> greater than equal to 
		-lt --> less than 
		-le --> less than equal to

Reading from and Writing to Files.
----------------------------------
	using redirection 
	
	
	command piping:
	---------------
		command1 | command2 
			Output of the first command is used as input for the second command. 
			
			first command's output is sent to the output device(stdout) which in turn is stored in the pipe, where second command is forced to take input from standard input device(stdin) which in turn is reading from the pipe. 

		The commands that can be used on the right hand side of the pipe (i.e., second command) is referred to as the filter command.

	Commonly used filter commands:
	----------------------------=
		wc   ---> Word count 
		sort --> Sorting data line by line or column wise
		cut  --> extracting certain column from a line 
		uniq ---> removes duplicates
		more --> viewing large file contents page by page(one way)
		
		less --> viewing large file contents page by page (two way)
		
		cat --> concatinating files 
		
		grep --> global Regular Expression print
		sed --> streamline editor
		awk --> 
		
Regular expression:
-------------------
	^Word --> begining of the line 
	Word$ --> End of the line 
	^Word$ --> first and last word in the line.
