History of OS:
--------------
	Ken Thompson --> UNIX in 1969 in Bell Labs.

	University of California, Berkeley.
	
	BSD version of UNIX

	In order to bring in Standardized UNIX... IEEE introduced POSIX (Portable OS Interface for UNIX)
	
	After POSIX standard was introduced., every UNIX Flavors started compliance to this standard.
	
	So by 1990, POSIX was the defacto standard for all UNIX like OS's.
	
	If you observe, People coming from Computer Science background, they study OS Concepts as their one of the subject.,

		os.minix.newsgroup
		
		This is the first version of Linux is 0.01 in 1991.
		
		This Linux was the core part of the OS we call it as Kernel.

When Linus Trovalds released his Linux, many components of GNU system were available except a complete Kernel which was missing. So Linux filled this gap, allowing users to combine GNU software with Linux kernel to create a fully functional(working) OS.

Creating, Listing, Deleting Files and Directories:
--------------------------------------------------
	rm --> removes files 
	rmdir --> removes empty folder/directory
	rm -r dirName --> Removes non-empty folder/directory along with its files recursively.

Copying, Moving, Removing Files:
--------------------------------
	cp --> copy file 
	cp -r srcdir destDir --> copy files along with srcdir directory into destDir directory recursively 
	cp file1 file2 file3 dirName --> copy multiple files into a single directory
	
	mv src dest --> moves source src into dest file 
		--> equal to cut and paste

	basic file creation...
	----------------------

		^O --> Ctrl + o

Vim Modes and Navigation:
------------------------	
	vi filename
		Opens the file in navigation mode(moving cursor).
		for example:
		  works like arrow(navigation) keys 
			h  --> left
			j  --> down
			k  --> up 
			l  --> right 

			w --> next word 
			b --> previous word 
		
			G --> Last line of the file 
			gg --> first line of the file 
			0 --> first character in the line 
			$ --> End of the line (last character)
			
			yy --> yank(copy) current line 
			2yy --> copy 2 lines from current line 

			dd --> Delete / cut current line 
			2dd --> Delete/cut 2 lines from current line 
			
			p  --> paste (next line)
			P  --> Paste (one line above)
	
			u --> Undo 
			Ctrl + r --> Redo 
	Last line command mode:
		when you type : (colon) from navigation mode 
			w --> write or save 
			w filename --> save as filename
			q --> quit 
			q! --> force quit 
			w! --> Save forcefully 
			x --> save and quit 
		
	Edit mode:
		Where you can start typing the contents in the file. You can press any one of the following keys from navigation mode.
		
		i --> Insert before the current cursor position 
		I --> Insert at the begining of the current line 
		a --> append before the current cursor position 
		A --> append at the end of the current line 
		o --> Inserting at Next line 
		O --> Inserting one line above 
		R --> Replace (Insert key in Windows)
		s --> Substitute single character 
		S --> Substitute single line
	--------------------------------
		After typing the contents come out of edit mode by pressing esc key. Once you press esc key, you move to navigation mode.
